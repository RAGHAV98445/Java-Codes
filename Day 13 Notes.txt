#Logging

 
Logging is the practise of recording events,actions and messages from appplications or systems info files,databases,or monitoring tools.


Importance of Logging:-

-troubleshooting-> help diagnose errors or failures quickly.
-Understanding Behaviour->  Tracks how users and systems behave over time.
-Auditing and Compilance -> Keeps how users and systems behave over time.
-Performance Monitoring-> Identifies bottlenecks or abnormal patterns.
-Reproductivity-> Lets you recreate steps that lead to an issue.
-Alerts & Notifications-> Enablesreal-time alerts when problems occur.

Common Login Use Case:-

Application Deugging->Log function entries ,variable values and logic flow.
Security-> Audits Record Logins
System Monitoring
User Activity Logs
Transaction logs
Error Tracking

#File Permission/Access Modes
                                                               
             

1.Permission Indicators:-


Position        Meaning Who it applies to 
-rwx              read,write,execute(enetr)(for owner or user)
 r-x                 (it is for group)  
 r--                 (for others)


 ## Changing Permissions:-

u->user
g->Group
o:others
a:All(u,g and o)

Permisssion Types:-

r:Read
w:write
x:Execute

Operators:-
+:Add Permission
-:Remove Permission
=: Set permission exactly


chmod u+w filename #Adds write permission for the owner
chmod g-x directory # Removes execute permission for the group
chmod a=rwx file.sh # Setsread,write,and execute permission


##Absolute(Octal Permissions)

Each Permission Number:-

Permission      Value
r                4
w                2
x                1


so,rwx=4+2+1=7
